# Matriz de trazabilidad (H07)

Trazabilidad completa de **requerimiento (RF / RNF) → caso de uso (CU) → historia de usuario (HU / Jira) → criterio de aceptación (CA) → implementación (Backend / Frontend) → Pull Request → prueba automatizada** para el 100 % de las historias entregadas en TexCore ERP.
